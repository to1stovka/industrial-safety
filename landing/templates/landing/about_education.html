{% chunk "about_edu_education_title" "Образование" %}

{% chunkblock "about_edu_education_01" %}

АНО ДПО «УЦ «Безопасность в промышленности» проводит образовательную деятельность на основании лицензии на осуществление образовательной деятельности серии 77Л01 № 0011942 (номер лицензии, присвоенный в Едином реестре учета лицензий: Л035-01298-77/00180425), выданной Департаментом образования и науки города Москвы от 25.09.2020г.

{% endchunkblock %} {% chunkblock "about_edu_education_02" %}

Реестр лицензий образовательных организаций

{% endchunkblock %} {% chunkblock "about_edu_education_03" %}

Программы АНО ДПО «Учебного центра «Безопасность в промышленности» рассчитаны на 16, 40 и 72 часа по очной форме обучения. Возможна разработка индивидуальных программ по договоренности с Заказчиком, а также обучение по заочной форме обучения (с применением дистанционных технологий)

{% endchunkblock %} {% chunkblock "about_edu_education_04" %}

Список программ обучения

{% endchunkblock %} {% chunkblock "about_edu_education_05" %}

К освоению дополнительных профессиональных программ допускаются: лица, имеющие среднее профессиональное и (или) высшее образование, а также лица, получающие среднее профессиональное и (или) высшее образование

{% endchunkblock %} {% chunkblock "about_edu_education_06" %}

Повышение квалификации проводится:
·      с отрывом от работы (очно);
·      без отрыва от работы заочно с применением дистанционных технологий;
·      по согласованию с организацией-заявителем возможен частичный отрыв от работы (изучение нормативно-технической документации дистанционно; тестирование - очно)

{% endchunkblock %} {% chunkblock "about_edu_education_07" %}

Для обеспечения процесса обучения с применением дистанционных образовательных технологий используются учебные материалы в электронном формате. С учетом наличия технических возможностей входное тестирование, промежуточное и итоговое тестирование могут проводиться с обучающимися в режиме on-line, а также с использованием электронных отправлений. После успешной итоговой аттестации в течение 14 дней выдается удостоверение о повышении квалификации с указанием названия курса и количества часов. Сведения о выданных удостоверениях по повышению квалификации вносятся в «Федеральный реестр сведений о документах об образовании и (или) о квалификации, документах об обучении (ФИС ФРДО) в течение 60 дней со дня выдачи удостоверения о повышении квалификации

{% endchunkblock %} {% chunkblock "about_edu_education_08" %}

Ограничений по количеству мест для обучения нет. Обучение предоставляется на коммерческой основе — по договору о платных образовательных услугах. Оплатить обучение может юридическое лицо

{% endchunkblock %} {% chunkblock "about_edu_education_09" %}

Обучение проводится на русском языке
