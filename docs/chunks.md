# Система фрагментов контента (Chunks)

## Описание

Система chunks позволяет управлять фрагментами контента на сайте через админ-панель Django. Это удобно для редактирования текстовых блоков без необходимости изменять шаблоны.

## Модель

**Модель:** `landing.models.Chunk`

**Поля:**
- `key` (CharField) - Уникальный ключ для идентификации фрагмента
- `content` (RichTextUploadingField) - HTML-контент с поддержкой CKEditor и загрузки изображений

## Использование в шаблонах

### 1. Подключение тега

В начале шаблона подключите библиотеку тегов:

```django
{% load chunk_tags %}
```

### 2. Базовое использование

```django
{% chunk 'chunk_key' %}
```

### 3. Использование с дефолтным значением

Если chunk с указанным ключом не существует в базе данных или его содержимое пустое, будет использовано дефолтное значение:

```django
{% chunk 'chunk_key' '<p>Дефолтный текст</p>' %}
```

## Примеры

### Пример 1: Простой текстовый блок

**В шаблоне:**
```django
{% load chunk_tags %}

<div class="about-section">
    <h2>О компании</h2>
    {% chunk 'about_company' '<p>Информация о компании пока не добавлена</p>' %}
</div>
```

**В админке:**
- Создайте Chunk с ключом `about_company`
- Добавьте HTML-контент в поле "Содержание"
- Сохраните

### Пример 2: Контактная информация

**В шаблоне:**
```django
{% load chunk_tags %}

<div class="contacts">
    {% chunk 'contact_phone' '<p>Телефон: 8 (495) 000-00-00</p>' %}
    {% chunk 'contact_email' '<p>Email: info@example.com</p>' %}
    {% chunk 'contact_address' '<p>Адрес: Москва, ул. Примерная, д. 1</p>' %}
</div>
```

### Пример 3: Блок с изображениями

Благодаря CKEditor можно вставлять изображения:

**В шаблоне:**
```django
{% load chunk_tags %}

<section class="promo">
    {% chunk 'promo_banner' '<div class="placeholder">Промо-баннер</div>' %}
</section>
```

**В админке:**
- Используйте кнопку вставки изображения в CKEditor
- Загрузите изображение
- Добавьте текст и оформление

### Пример 4: Сложный HTML-контент

**В шаблоне:**
```django
{% load chunk_tags %}

<div class="features">
    {% chunk 'features_list' '<ul>
        <li>Функция 1</li>
        <li>Функция 2</li>
        <li>Функция 3</li>
    </ul>' %}
</div>
```

## Работа с админ-панелью

1. Перейдите в раздел **"Фрагменты контента"** в админ-панели
2. Нажмите **"Добавить фрагмент контента"**
3. Введите **ключ** (должен совпадать с ключом в шаблоне)
4. Заполните **содержание** с помощью визуального редактора CKEditor
5. Сохраните

## Особенности

### Безопасность
Контент из chunks автоматически помечается как безопасный (`mark_safe`) для отображения HTML.

### Кэширование
По умолчанию chunks загружаются из базы данных при каждом запросе. Для высоконагруженных сайтов рекомендуется добавить кэширование.

### Дефолтные значения
Всегда указывайте дефолтное значение, чтобы страница корректно отображалась, даже если chunk не создан в админке:

```django
{% chunk 'key' 'Default content' %}
```

## Реальный пример (страница контактов)

```django
{% extends 'landing/base.html' %}
{% load static %}
{% load chunk_tags %}

{% block content %}
<section class="contact-section">
  <div class="container">
    <h1>Контакты</h1>

    <div class="about-center">
      <h2>О центре</h2>
      {% chunk 'contact_about' '<p>Информация о центре</p>' %}
    </div>

    <div class="contact-info">
      {% chunk 'contact_address' '<p>Адрес не указан</p>' %}
      {% chunk 'contact_phone' '<p>Телефон не указан</p>' %}
      {% chunk 'contact_email' '<p>Email не указан</p>' %}
      {% chunk 'contact_hours' '<p>График работы не указан</p>' %}
    </div>

    <div class="map">
      {% chunk 'contact_map' '<div>Карта</div>' %}
    </div>
  </div>
</section>
{% endblock %}
```

## Советы

1. **Именование ключей**: Используйте понятные префиксы (например, `contact_`, `about_`, `footer_`)
2. **Группировка**: Группируйте связанные chunks по префиксам для удобства поиска в админке
3. **Дефолты**: Всегда предоставляйте осмысленные дефолтные значения
4. **Документирование**: Создавайте chunks в админке с описательными ключами
